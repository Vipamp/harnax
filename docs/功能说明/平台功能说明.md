# Harnax（OpenDuck）平台功能说明

> 本文档面向平台使用者，介绍 Harnax 管理控制台（WebUI）的全部功能。无需了解技术细节，按菜单模块阅读即可。

## 平台是什么

Harnax 是一个企业级 AI 智能体（Agent）平台。你可以在平台上：

- 配置自己的 AI 智能体，接入多种大模型（阿里云百炼、OpenAI 兼容服务、本地 Ollama 等）
- 给智能体挂载工具、技能、MCP 服务和命令行环境，让它能查资料、读写文件、执行任务
- 把智能体接入飞书、微信、钉钉、企业微信，让同事直接在聊天软件里使用
- 在网页上直接和智能体对话，实时看到它的思考过程和任务计划
- 设置定时任务，让智能体自动定期执行工作
- 监控 Token 用量和费用，管理用户、租户与权限

## 使用方式一览

| 使用方式 | 适合谁 | 说明 |
|---|---|---|
| 网页控制台 | 平台内用户 | 登录后在「会话对话」页面直接和 AI 聊天 |
| 聊天软件机器人 | 全体同事 | 在飞书 / 微信 / 钉钉 / 企业微信里 @机器人 对话 |
| API 调用 | 开发者 / 外部系统 | 申请 API Key 后调用平台开放接口 |

## 一、登录与首页

- **账号登录**：用户名 + 密码 + 图形验证码，密码在浏览器端加密后才传输
- **手机号登录**：手机号 + 短信验证码
- **第三方登录**：GitHub 账号一键登录
- 支持「记住我」，下次免输密码

### 欢迎页（首页）

登录后进入首页，一眼看到平台概况：

- 动态统计卡片：已集成模型数、工具数量、今日请求数、活跃用户数
- 平台能力介绍：多模型集成、MCP 协议、Skills 技能、企业级安全、实时监控、开放 API

## 二、智能体模块

### 1. 智能体管理

创建和管理你的 AI 智能体。**创建过程采用 5 步向导**，一步步引导完成：

| 步骤 | 配置内容 |
|---|---|
| ① 基本信息 | 名称、描述、头像、系统提示词（告诉智能体"你是谁、能做什么"）、绑定模型、负责人、是否公开 |
| ② 工具配置 | 勾选要授权给智能体的内置工具（按功能分组勾选） |
| ③ MCP 配置 | 接入外部 MCP 能力服务 |
| ④ 技能配置 | 勾选已同步的技能包 |
| ⑤ CLI 配置 | 勾选命令行工具（如 git、node 等运行环境） |

贴心细节：

- **能力智能过滤**：选定模型后，只显示该模型真正支持的能力开关（联网搜索、深度思考、工具调用、MCP、视觉识别），不会让你配置用不了的功能
- **卡片式列表**：每个智能体以卡片展示，鼠标悬停即可查看它挂载的工具、MCP、技能、CLI 和关联会话明细
- **配置热更新**：修改智能体后，可选择性刷新正在使用它的会话，新配置立即生效，无需重建会话

### 2. 会话对话（核心功能）

在网页上直接和智能体聊天，界面为「左侧会话列表 + 中间聊天窗口 + 右侧工作空间抽屉」。

**会话管理**：多会话切换、置顶、改名、删除、新建。

**聊天窗口**：

- 顶部状态条实时显示：智能体名称、当前模型、深度思考 / 联网 / 计划模式开关状态、权限模式、消息数、Token 用量、耗时
- 回复实时流式输出，支持 Markdown 排版和代码高亮
- 消息支持富内容展示：
  - **思考过程**：AI 的推理过程可展开 / 折叠查看
  - **工具调用卡片**：清楚展示 AI 调用了什么工具、传了什么参数、返回了什么结果
  - **计划卡片**：复杂任务自动拆解为子任务清单，实时显示每项的状态（待办 / 进行中 / 已完成 / 已放弃）
- 支持拖拽上传文件提问：图片、PDF、Word、Excel、PPT、代码文件等几十种格式

**工具调用确认与权限模式**（5 档，随时切换）：

| 模式 | 效果 |
|---|---|
| 默认询问 | 每次工具调用都弹窗请你确认 |
| 接受编辑 | 文件修改类操作自动放行，其余仍询问 |
| 只读探索 | 只允许读取，不允许修改 |
| 全部放行 | 本轮不再询问 |
| 不再询问 | 本次会话永久放行 |

**斜杠命令**：输入框中键入 `/` 即可唤出快捷命令：

| 命令 | 作用 |
|---|---|
| `/interrupt` | 中断当前回复 |
| `/stop` | 停止智能体执行 |
| `/clear` | 清空上下文 |
| `/compact` | 压缩上下文，节省 Token |
| `/approve` | 批准待确认的工具调用 |
| `/enable` `/disable` | 开关某项能力（思考 / 联网 / 计划 / 工具 / MCP / CLI） |
| `/permission` | 切换权限模式 |
| `/stop-sandbox` | 停止沙箱环境 |

**工作空间抽屉**：每个会话有独立的沙箱文件空间，可在线浏览目录（面包屑导航）、新建、上传、下载、删除文件——AI 生成的文件随手可取。

### 3. 定时任务

让智能体按计划自动干活，比如每天早上生成日报、每小时巡检一次。

**任务配置**：

- 任务名称、描述、关联智能体、是否公开
- **提示词**：每次执行时发给智能体的指令
- **执行周期**：Cron 表达式，并内置常用预设（每 5 分钟 / 每小时 / 每天 9 点 / 每周一 9 点 / 每天 0 点），不懂 Cron 也能用
- **超时时间**：30 ~ 3600 秒
- **并发开关**：同一任务是否允许多个实例同时运行

**运行控制**：启用 / 暂停、立即执行一次、停止运行中的任务。

**执行结果自动判定**：成功 / 失败 / 超时 / 执行中 / 停止中 / 已停止，每次执行都留有详细日志可查。

## 三、上下文管理模块

这个模块管理智能体可以使用的各种「能力素材」：模型、工具、MCP 服务、技能、CLI 工具、聊天通道。

### 1. 模型管理

分「服务商」和「模型」两个视图。

**服务商**（从哪家 AI 厂商接入）：

- 支持三类：**阿里云百炼（DashScope）**、**OpenAI 兼容服务**（覆盖绝大多数模型厂商）、**Ollama**（本地私有化部署）
- 配置项：名称、描述、API Key（密码框保护，只写不显示）、接入地址、是否公开
- 一键**连通性测试**，接入前先验证可用性
- 卡片上直接显示该服务商下的模型统计

**模型**（具体用哪个模型）：

- 模型类型：对话模型 / 向量模型（用于语义检索）
- 配置项：显示名称、真实模型 ID（如 `qwen-plus`）、描述
- **分开定价**：输入、输出 Token 单价分别设置（元 / 千 Token），费用统计自动按此计算
- **能力标签**：联网搜索、深度思考、工具调用、MCP、视觉识别——决定该模型在智能体配置中能开哪些开关
- 支持按标签多选筛选、按价格区间筛选、一键启停

### 2. 工具管理

平台内置工具按功能分组，可整组授权给智能体：

| 分组 | 能力 |
|---|---|
| 文件操作 | 读、写、追加、列目录、删除、改名 |
| 代码执行 | 在沙箱中安全运行命令 |
| 搜索 | 按内容搜索文件、按文件名搜索 |
| 任务管理 | 创建 / 更新子任务（对应聊天里的计划卡片） |
| 工作空间 | 启动 / 停止沙箱环境 |

- 工具带中英文名称和说明，按名称可搜索
- 需要密钥或环境变量的工具有图标提示
- 未授权的工具被 AI 调用时会弹窗请你临时确认，安全可控

### 3. MCP 服务管理

MCP（Model Context Protocol）是给 AI 扩展外部能力的开放标准，接入一个 MCP 服务，智能体就自动获得它的全部工具。

- 新增 / 编辑 / 删除 MCP 服务，支持三种连接方式（stdio / SSE / Streamable HTTP）
- 一键**连通性测试**，确认服务可用再上线
- 详情页**自动发现并展示**该服务提供的所有工具及参数说明
- 启用 / 停用、搜索、按状态和类型筛选

### 4. 技能管理

技能（Skill）是可复用的能力包——一组预设提示词加资源文件，例如某领域知识包、标准工作流模板。

**第一步，配置技能来源**，支持三种：

| 来源 | 配置方式 |
|---|---|
| Git 仓库 | 填仓库地址 + 分支名 |
| NPM 包 | 填包名 + NPM 源地址 |
| ZIP 上传 | 直接上传压缩包 |

**第二步，一键同步**：

- 系统自动拉取来源中的全部技能，弹出清单
- 已有技能标「已存在」（默认勾选更新），新技能标「新」（默认勾选导入）
- 确认后批量保存，随后即可在智能体配置中勾选使用

每个技能包含名称、版本、描述、使用说明文档（SKILL.md）和资源文件，可查看详情、单独启停。

### 5. CLI 工具管理

给智能体的沙箱运行环境预装命令行工具（如 git、node）。

- 新增 / 编辑 / 删除 / 启停
- 保存时自动提示哪些智能体绑定了该工具、会影响哪些会话，改动心里有数

### 6. 通道管理

把智能体接入聊天软件，让同事在 IM 里直接 @机器人使用。

| 通道 | 接入方式 | 需要填写 |
|---|---|---|
| 飞书 | 长连接，无需公网回调 | App ID、App Secret |
| 钉钉 | Stream 模式 | App Key、App Secret |
| 企业微信 | 长连接 | 机器人 ID、机器人密钥 |
| 微信（个人号） | **扫码即用** | 无需填写，扫码绑定 |
| HTTP 自定义 | Webhook | 回调地址 |

- 每个通道绑定一个智能体，可单独设置权限模式和深度思考 / 联网 / 计划模式开关
- **微信扫码接入**是亮点：页面弹出二维码，手机微信一扫，实时显示扫码进度（等待扫码 → 已扫码 → 登录成功），成功后凭证自动保存，机器人即刻上线

## 四、系统管理模块（仅管理员可见）

### 1. 用户管理

- 新增 / 编辑 / 删除用户（用户名、密码、邮箱、手机号）
- 按用户名 / 邮箱 / 手机号搜索，按状态、租户筛选
- 一键启用或停用账号
- 管理用户属于哪些租户

### 2. 租户管理

租户用于企业内不同团队 / 组织之间的数据隔离。

- 新建 / 删除租户（仅全局管理员）、启用 / 停用
- 管理租户成员：添加用户、移除用户、修改成员角色
- **数据默认按租户隔离**；需要共享时，把模型 / 智能体 / MCP 等资源的「是否公开」打开，其他租户即可看到并使用

### 3. Token 监控

看清 AI 用了多少量、花了多少钱。

**7 个汇总卡片**：总费用（元）、总输入 Token、总输出 Token、总消耗 Token、活跃智能体数、活跃会话数、使用的模型数。

**6 张图表**：

- 3 张饼图：按模型 / 按智能体 / 按会话的消耗占比
- 3 张折线图：对应维度的时间趋势

**灵活筛选**：时间范围自选，粒度可切小时 / 天 / 月，统计口径可在「Token 数量」和「费用金额」之间一键切换——技术同学看用量，财务同学看钱。

### 4. API Key 管理

外部系统调用平台时使用的密钥。

- 创建时可配置：名称、**权限范围**（对话接口 / 管理接口，可多选）、绑定租户、**速率限制**（1 ~ 10000 次/分钟，默认 60）、**过期时间**（留空即长期有效，填写则到期自动失效）
- Key 明文仅在创建时完整显示一次，请及时保存
- 支持**重新生成**：旧 Key 立即失效，适合泄露后紧急更换
- 列表可查看所属租户、是否过期、最后使用时间、累计调用次数
- 普通用户只能管理自己的 Key，管理员可查看全部

### 5. 环境变量管理

保存智能体运行时需要的密钥、配置等敏感信息。

- 新增 / 编辑 / 删除 / 启停，只能看到自己创建的变量
- 敏感值默认打码显示，点击眼睛图标可临时查看
- 配置智能体时可直接从下拉框选用，不必把密钥写进提示词
