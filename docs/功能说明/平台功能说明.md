# Harnax（OpenDuck）平台功能说明

> 本文档面向平台使用者，介绍 Harnax 管理控制台（WebUI）的功能与使用规则。无需了解技术细节，按菜单模块阅读即可。

## 平台是什么

Harnax 是一个企业级 AI 智能体（Agent）平台。你可以在平台上：

- 配置自己的 AI 智能体，接入多种大模型（阿里云百炼、OpenAI 兼容服务、本地 Ollama 等）
- 给智能体挂载工具、技能、MCP 服务和命令行环境，让它能查资料、读写文件、执行任务
- 把智能体接入飞书、微信、钉钉、企业微信，让同事直接在聊天软件里使用
- 在网页上直接和智能体对话，实时看到它的思考过程和任务计划
- 设置定时任务，让智能体自动定期执行工作
- 监控 Token 用量和费用，管理用户、租户与权限

## 使用方式一览

| 使用方式 | 适合谁 | 说明 |
|---|---|---|
| 网页控制台 | 平台内用户 | 登录后在「会话」页面直接和 AI 聊天 |
| 聊天软件机器人 | 全体同事 | 在飞书 / 微信 / 钉钉 / 企业微信里和机器人对话，详见第六章 |
| API 调用 | 开发者 / 外部系统 | 申请 API Key 后调用平台开放接口，详见《外部系统接入指南》 |

## 快速上手：必须按顺序完成的四步

平台各配置之间存在依赖关系，**从零开始必须按以下顺序**，否则下一步无法进行：

```
① 添加服务商 ──→ ② 添加模型 ──→ ③ 创建智能体 ──→ ④ 新建会话开聊
   (填 API Key)     (绑定服务商)     (必须选模型)      (必须选智能体)
```

| 步骤 | 位置 | 依赖规则 |
|---|---|---|
| ① 添加服务商 | 模型管理 → 服务商 | 无前置依赖，建议先做连通性测试 |
| ② 添加模型 | 模型管理 → 模型 | 必须挂在已有服务商下；同一服务商下模型名称不可重复 |
| ③ 创建智能体 | 智能体管理 | **必须选择一个模型**，没有可用模型时无法创建；工具 / MCP / 技能 / CLI 均可选、可跳过 |
| ④ 新建会话 | 会话 | **必须选择一个智能体**；会话名称全局唯一，重名会被拒绝 |

相关联动规则：

- 启用某个模型时，它所属的服务商必须处于启用状态，否则操作被拒绝
- 服务商下还有启用中的模型时，**不能停用或删除该服务商**——需先处理完下面的模型

## 一、登录与账号

### 首次登录

系统初始化后自带一个管理员账号：

- 用户名：`admin`，初始密码：`admin123`，默认归属「Default Organization」租户
- **首次登录后请立即修改密码**

### 登录方式

- **账号登录**：用户名 + 密码 + 图形验证码，密码在浏览器端加密后才传输
- **手机号登录**：手机号 + 短信验证码
- **第三方登录**：GitHub 账号一键登录
- 支持「记住我」，下次免输密码

### 账号规则（重要）

- 平台**不支持自助注册**，账号由管理员在「用户管理」中创建
- 非管理员用户**必须归属至少一个租户**才能登录，否则登录被拒绝——新账号登不上时请先联系管理员分配租户
- 账号创建时系统自动为你生成一把「永久 API Key」，登录后即可在 API Key 管理中查看
- 属于多个租户的用户，登录时默认进入第一个租户

### 欢迎页（首页）

- 动态统计卡片：已集成模型数、工具数量、今日请求数、活跃用户数
- 平台能力介绍：多模型集成、MCP 协议、Skills 技能、企业级安全、实时监控、开放 API

## 二、资源可见性与"公开"规则（通用逻辑）

平台上的智能体、模型、服务商、MCP、技能、CLI、会话都遵循同一套可见性规则，先理解这套规则再看后面的模块：

| 规则 | 说明 |
|---|---|
| 你能看到什么 | **自己创建的资源** + **别人设为公开的资源**；他人的私有资源对你完全不可见 |
| 公开 = 只读共享 | 别人公开的资源你**只能查看和使用，不能编辑或删除** |
| 公开不可撤回 | 资源一旦设为公开，**不能再改回私有**，设置前请想清楚 |
| 编辑权限 | 只有创建者本人能编辑自己的资源 |

## 三、智能体模块

### 1. 智能体管理

创建和管理你的 AI 智能体。**创建过程采用 5 步向导**：

| 步骤 | 配置内容 | 是否必填 |
|---|---|---|
| ① 基本信息 | 名称、描述、头像、系统提示词、**绑定模型**、负责人、是否公开 | 模型必选 |
| ② 工具配置 | 勾选授权给智能体的内置工具（按功能分组） | 可跳过 |
| ③ MCP 配置 | 接入外部 MCP 能力服务 | 可跳过 |
| ④ 技能配置 | 勾选已同步的技能包 | 可跳过 |
| ⑤ CLI 配置 | 勾选命令行工具（如 git、node 运行环境） | 可跳过 |

**能力智能过滤**：选定模型后，只显示该模型真正支持的能力开关（联网搜索、深度思考、工具调用、MCP、视觉识别）——模型不支持的功能不会让你误开。

**修改智能体后配置怎么生效**（重要逻辑）：

- 保存时会列出正在使用该智能体的会话，让你**勾选需要立即生效的会话**
- 勾选的会话立刻用新配置重建；**未勾选的会话约 30 分钟内自动生效**
- 也就是说：改了提示词或换了模型后，老会话不会瞬间全变，你可以控制生效节奏

**删除智能体的影响**：

- 智能体上挂的工具、MCP、技能、CLI 绑定关系一并清除
- 已有会话**不会被删除**，但其背后的智能体已不存在，建议先处理完会话再删智能体

### 2. 会话（核心功能）

界面为「左侧会话列表 + 中间聊天窗口 + 右侧工作空间抽屉」。

**会话的基本逻辑**：

- 新建会话必须选择一个智能体，填写全局唯一的会话名称
- 创建那一刻，会话会**复制智能体当时的配置快照**（提示词、模型、MCP、技能等）——之后智能体改了配置，会话按上文的"生效规则"更新
- 会话可以更换绑定的智能体，多会话之间支持切换、置顶、改名、删除

**聊天窗口**：

- 顶部状态条实时显示：智能体名称、当前模型、能力开关状态、权限模式、消息数、Token 用量、耗时
- 快捷开关按钮：**深度思考**、**联网搜索**、**开启计划**、**自动执行**，点一下即切换，对本会话持续生效
- 回复实时流式输出，支持 Markdown 排版和代码高亮，代码块带一键复制
- 消息富内容展示：
  - **思考过程**：AI 的推理过程可展开 / 折叠查看
  - **工具调用卡片**：AI 调用了什么工具、传了什么参数、返回了什么结果，一目了然
  - **计划卡片**：复杂任务自动拆解为子任务清单，实时显示状态（待办 / 进行中 / 已完成 / 已放弃）
- 支持上传多张图片提问（配合支持视觉能力的模型）；其他类型文件请通过右侧工作空间上传给 AI 使用
- 输入框：Enter 发送，Shift + Enter 换行，高度随内容自动伸缩
- 「清空聊天记录」按钮带二次确认，清空后 AI 不再记得之前的内容

**工具确认逻辑**（什么时候会弹窗问你）：

弹不弹确认窗由三层因素共同决定：

1. **工具本身**是否标记为"需要确认"——不需要确认的工具永远静默执行
2. **智能体配置**中可以对需要确认的工具再做选择
3. **会话的权限模式**（5 档，界面用语如下）最终决定行为：

| 界面选项 | 效果 |
|---|---|
| 默认（危险工具需确认） | 危险 / 需确认的工具调用弹窗请你确认 |
| 自动执行（无需确认） | 所有工具自动执行，不再询问 |
| 接受编辑（自动批准文件操作） | 文件修改类操作自动放行，其余仍询问 |
| 探索模式（只读） | 只允许读取类操作，不允许修改 |
| 禁止执行（自动拒绝危险工具） | 危险工具一律自动拒绝 |

**危险输入强制拦截**（安全底线）：部分工具会对输入内容做危险模式扫描（如删除命令 `rm -rf`、敏感文件 `.env`、`.ssh` 等）。一旦命中，**无论当前处于哪种权限模式（包括"自动执行"）都会强制弹窗确认**——这是绕不过的安全防线。确认弹窗中高风险操作带红色「高风险」标记，请核对参数后再批准。

**斜杠命令**：输入框中键入 `/` 唤出快捷命令：

| 命令 | 作用 |
|---|---|
| `/interrupt` `/stop` | 中断当前回复 / 停止执行 |
| `/clear` | 清空上下文（历史清除后 AI 不再记得之前聊的内容） |
| `/compact` | 压缩上下文——把长对话总结成摘要继续聊，省 Token 又不断上下文 |
| `/approve` `/deny` | 批准 / 拒绝待确认的工具调用 |
| `/enable` `/disable` | 开关会话能力（thinking 思考 / search 联网 / plan 计划） |
| `/permission` | 切换上表的权限模式 |
| `/stop-sandbox` | 停止沙箱环境 |

**工作空间（沙箱）**：

- 每个会话拥有独立的沙箱环境，AI 在里面读写文件、执行代码，**不会影响其他会话**
- 沙箱在你发送消息时按需创建；不用时可手动「停止沙箱」释放资源，**工作区文件快照会保存**，不会丢
- 右侧抽屉可在线浏览沙箱目录（面包屑导航）、新建、上传、下载、删除文件——AI 生成的产物随手可取

### 3. 定时任务

让智能体按计划自动干活，比如每天早上生成日报、每小时巡检一次。

**任务配置**：

- 任务名称、描述、关联智能体、是否公开
- **提示词**：每次执行时发给智能体的指令
- **执行周期**：Cron 表达式，内置常用预设（每 5 分钟 / 每小时 / 每天 9 点 / 每周一 9 点 / 每天 0 点），不懂 Cron 也能用
- **超时时间**：30 ~ 3600 秒，默认 300 秒（5 分钟），超时的执行会被标记为「超时」
- **并发开关**：关闭时，上一次执行没结束前**不允许再次触发**（手动触发会提示"任务正在运行中"）；打开则允许多个实例同时跑

**执行逻辑**（重要）：

- **每次执行都新建一个独立会话**，执行结束后自动清理——所以每次执行都是"从零开始"，任务之间**不共享上下文**；需要 AI 记住历史，请把必要信息写进提示词
- 任务有两个独立状态：任务本身的「运行中 / 暂停」，和每次执行的结果（成功 / 失败 / 超时 / 执行中 / 停止中 / 已停止）
- 支持立即执行一次、暂停、停止运行中的任务（停止即向 AI 发送中断指令）
- 每次执行都会生成一条执行日志，记录发出的提示词、AI 的完整回复、耗时和错误信息
- 任务失败**不会自动重试**，需人工查看日志后手动再触发
- 系统重启时会自动把遗留的"执行中"记录标记为超时，不会出现永远卡在执行中的假状态

## 四、上下文管理模块

管理智能体可使用的「能力素材」：模型、工具、MCP 服务、技能、CLI 工具、聊天通道。

### 1. 模型管理

分「服务商」和「模型」两个视图，**先有服务商才能建模型**。

**服务商**（从哪家 AI 厂商接入）：

- 支持三类：**阿里云百炼（DashScope）**、**OpenAI 兼容服务**（覆盖绝大多数模型厂商）、**Ollama**（本地私有化部署）
- 配置项：名称、描述、API Key（密码框保护，只写不显示）、接入地址、是否公开
- 一键**连通性测试**，接入前先验证可用性
- **保护规则**：服务商下还有启用中的模型时，不能停用；还有模型存在时，不能删除

**模型**（具体用哪个模型）：

- 模型类型：对话模型 / 向量模型（用于语义检索）
- 配置项：显示名称、真实模型 ID（如 `qwen-plus`）、描述
- **分开定价**：输入、输出单价分别设置，单位为**元 / 百万 Token**；Token 监控中的费用按此价格自动计算——价格填错，费用统计就不准
- **能力标签**：联网搜索、深度思考、工具调用、MCP、视觉识别——决定该模型在智能体配置中能开哪些开关
- 支持按标签多选筛选、按价格区间筛选、一键启停
- 注意：删除模型前请自查是否有智能体正在使用它，平台不会阻止删除，但引用它的智能体会无法正常对话

### 2. 工具管理

平台内置工具按功能分组，可整组授权给智能体：

| 分组 | 能力 |
|---|---|
| 文件操作 | 读、写、追加、列目录、删除、改名 |
| 代码执行 | 在沙箱中安全运行命令 |
| 搜索 | 按内容搜索文件、按文件名搜索 |
| 任务管理 | 创建 / 更新子任务（对应聊天里的计划卡片） |
| 工作空间 | 启动 / 停止沙箱环境 |

- 每个工具自带「是否需要确认」属性，与会话权限模式共同决定执行前是否弹窗（见会话章节）
- 需要密钥或环境变量的工具有图标提示
- 未授权给智能体的工具被 AI 调用时会弹窗请你临时确认，安全可控

### 3. MCP 服务

MCP（Model Context Protocol）是给 AI 扩展外部能力的开放标准，接入一个 MCP 服务，智能体就自动获得它的全部工具。

- 新增 / 编辑 / 删除 MCP 服务，支持三种连接方式（stdio / SSE / Streamable HTTP）
- 一键**连通性测试**，确认服务可用再上线
- 详情页**自动发现并展示**该服务提供的所有工具及参数说明
- 特殊规则：MCP 一旦设为公开，**不能改回私有**

### 4. 技能管理

技能（Skill）是可复用的能力包——一组预设提示词加资源文件，例如某领域知识包、标准工作流模板。

**第一步，配置技能来源**，支持三种：

| 来源 | 配置方式 |
|---|---|
| Git 仓库 | 填仓库地址 + 分支名 |
| NPM 包 | 填包名 + NPM 源地址 |
| ZIP 上传 | 直接上传压缩包 |

**第二步，一键同步**：

- 系统拉取来源中的全部技能，弹出清单：已有技能标「已存在」（默认勾选更新），新技能标「新」（默认勾选导入）
- **重复同步的规则**：同名技能会被远端版本**覆盖**（描述、文档、资源、版本号全部更新）——如果你在平台上改过某个技能，再次同步会被冲掉
- 确认后批量保存，即可在智能体配置中勾选使用

**内置技能仓库的限制**：平台自带的内置仓库（CLI 技能）为只读，其中的技能不可修改、不可删除，也不能被智能体直接勾选——它们随 CLI 工具自动加载。

**删除的连锁规则**：删除技能时，它与智能体、CLI 的绑定关系会自动解除；但删除技能仓库不会连带删除已同步的技能。

### 5. CLI 工具

给智能体的沙箱运行环境预装命令行工具（如 git、node）。

- 新增 / 编辑 / 删除 / 启停
- **保护规则**：还有智能体绑定着某个 CLI 时，**既不能停用也不能删除**——必须先在那些智能体里解绑。操作时平台会明确列出是哪些智能体在用

### 6. Channel 管理（接入聊天软件）

把智能体接入聊天软件，让同事在 IM 里直接使用。

| 通道 | 接入方式 | 需要填写 |
|---|---|---|
| 飞书 | 长连接，无需公网回调 | App ID、App Secret |
| 钉钉 | Stream 模式 | App Key、App Secret |
| 企业微信 | 长连接 | 机器人 ID、机器人密钥 |
| 微信（个人号） | **扫码即用** | 无需填写，扫码绑定 |
| HTTP 自定义 | Webhook | 回调地址 |

通道的工作逻辑：

- 每个通道**必须绑定一个智能体**，创建时系统自动生成回调密钥
- 通道可单独设置权限模式和深度思考 / 联网 / 计划模式开关，与网页端会话互不影响
- **微信扫码接入**：页面弹出二维码，手机微信一扫，实时显示进度（等待扫码 → 已扫码 → 登录成功），成功后凭证自动保存，机器人即刻上线

## 五、系统管理模块（仅管理员可见）

### 1. 用户管理

- 新增 / 编辑 / 删除用户（用户名、密码、邮箱、手机号），一键启停账号
- 按用户名 / 邮箱 / 手机号搜索，按状态、租户筛选
- **创建用户时的自动动作**：系统同时为该用户生成一把永久 API Key
- **记得分配租户**：不属于任何租户的普通用户无法登录

### 2. 租户管理

租户用于企业内不同团队 / 组织之间的隔离。

- 新建 / 删除租户（仅全局管理员），启用 / 停用
- 创建租户时需指定一名租户管理员，该用户自动以管理员角色加入
- 管理租户成员：添加用户、移除用户、修改成员角色
- 跨租户共享靠资源的「是否公开」开关：公开资源全平台可见可用，但只有创建者能改

### 3. Token 监控

看清 AI 用了多少量、花了多少钱。

**统计逻辑**：每轮对话结束即实时记账；费用 = 模型设置的单价（元 / 百万 Token）× 实际用量（输入、输出分开计），所以模型价格务必填准。

**7 个汇总卡片**：总费用（元）、总输入 Token、总输出 Token、总消耗 Token、活跃智能体数、活跃会话数、使用的模型数。

**6 张图表**：

- 3 张饼图：按模型 / 按智能体 / 按会话的消耗占比
- 3 张折线图：对应维度的时间趋势

**灵活筛选**：时间范围自选，粒度可切小时 / 天 / 月，统计口径可在「Token 数量」和「费用金额」之间一键切换——技术同学看用量，财务同学看钱。

### 4. API Key 管理

外部系统调用平台时使用的密钥。平台上有两类 Key，行为不同：

| | 普通 Key（临时） | 永久 Key |
|---|---|---|
| 来源 | 手动创建 | 创建用户时系统自动生成，一人一把 |
| 过期时间 | 可设置，留空则长期有效 | 永不过期 |
| 编辑 / 删除 / 停用 | 都可以 | 都不可以，只能「重新生成」 |
| 明文查看 | 仅创建时显示一次 | 登录后随时可查看 |
| 默认限流 | 60 次/分钟（可调 1 ~ 10000） | 300 次/分钟 |

通用规则：

- **重新生成**后旧 Key **立即失效**，所有使用旧 Key 的客户端必须更新——适合泄露后紧急更换
- 创建时可配置权限范围（对话 / 管理接口）、绑定租户；普通用户只能绑定自己的租户，管理员可指定任意租户
- 普通用户只能管理自己创建的 Key，管理员可查看全部
- 列表展示所属租户、是否过期、最后使用时间、累计调用次数

### 5. 环境变量管理

保存智能体运行时需要的密钥、配置等敏感信息。

- 新增 / 编辑 / 删除 / 启停，只能看到自己创建的变量
- 敏感值默认打码显示，点击眼睛图标可临时查看
- 配置智能体时可直接从下拉框选用，不必把密钥写进提示词

## 六、在聊天软件里使用（IM 端指南）

管理员配好通道后，同事就能在熟悉的聊天软件里直接使用 AI。各平台使用体验略有差异：

### 怎么和机器人说话

| 平台 | 私聊 | 群聊 |
|---|---|---|
| 飞书 | 直接发消息 | 需要 **@机器人** |
| 钉钉 | 直接发消息 | 需要 **@机器人** |
| 企业微信 | 直接发消息 | 需要 **@机器人** |
| 微信（个人号） | 直接发消息 | 直接发消息 |

### 上下文共享范围（重要）

- **飞书 / 钉钉 / 企业微信的群聊**：整个群共享同一份对话上下文——群里 A 问过的问题，B 接着问时 AI 是记得的，适合团队协作场景；注意不要在群里聊私密内容
- **私聊**：每个人（或每个私聊窗口）独立上下文，互不干扰
- **微信**：始终按用户隔离，每人一份独立上下文

### 回复方式

- IM 端的回复是**整段送达**（不是逐字流式）：AI 思考期间部分平台会显示"正在输入"，处理完成后一次性发出完整回答
- 超长回答会自动分成多条消息发送，不会被截断丢失
- 飞书支持直接发图片给 AI 识别（需模型具备视觉能力）；微信端图片暂不支持识别

### IM 里也能用命令

网页端的斜杠命令在 IM 里同样有效，直接发送即可：

- `/clear` 清空上下文、`/compact` 压缩上下文、`/interrupt` 中断
- **工具确认**：AI 需要执行敏感操作时，会在聊天里发出确认消息，列出工具名和参数（危险操作带 dangerous 标记），回复 `/approve` 批准、`/deny` 拒绝

## 附一：删除 / 停用连锁规则速查

| 想操作 | 前置条件 / 后果 |
|---|---|
| 停用 / 删除服务商 | 其下还有启用 / 存在的模型时被拒绝，先处理模型 |
| 删除模型 | 不做拦截，但引用它的智能体会无法对话，请先自查 |
| 启用模型 | 所属服务商必须是启用状态 |
| 停用 / 删除 CLI | 有智能体绑定时被拒绝，先去解绑 |
| 删除技能 | 自动解除与智能体 / CLI 的绑定 |
| 删除技能仓库 | 已同步的技能保留不动 |
| 删除智能体 | 绑定关系全部清除；已有会话保留但失去可用智能体 |
| MCP 设为公开 | 不可撤回，无法改回私有 |
| 重新生成 API Key | 旧 Key 立即失效 |
