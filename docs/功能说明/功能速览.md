# Harnax 功能速览（一页版）

> 适合快速了解平台能做什么。详细说明见 [平台功能说明](./平台功能说明.md)，开发者集成请看 [外部系统接入指南](./外部系统接入指南.md)。

## 功能地图

```
Harnax 平台
├── 登录与首页
│   ├── 账号密码 / 短信验证码 / GitHub 登录（默认管理员 admin，首登请改密码）
│   └── 首页概览（模型数、工具数、今日请求、活跃用户）
│
├── 智能体
│   ├── 智能体管理 —— 5 步向导创建、配置、启停 AI 智能体
│   ├── 会话 —— 网页上和 AI 聊天（流式回复、传图、思考过程、计划卡片、工具确认、沙箱工作空间）
│   └── 定时任务 —— 让 AI 按计划自动执行工作（每次执行独立会话）
│
├── 上下文管理
│   ├── 模型管理 —— 接入阿里云百炼 / OpenAI 兼容 / Ollama，输入输出分开定价
│   ├── 工具管理 —— 浏览平台内置工具（文件、代码执行、搜索、任务、工作空间）
│   ├── MCP 服务 —— 接入外部能力服务，自动发现工具
│   ├── 技能管理 —— 从 Git / NPM / ZIP 同步技能包
│   ├── CLI 工具 —— 给 AI 沙箱预装命令行工具
│   └── Channel 管理 —— 接入飞书 / 微信 / 钉钉 / 企业微信机器人
│
└── 系统管理（管理员）
    ├── 用户管理 —— 账号增删改查、启停、租户分配
    ├── 租户管理 —— 多团队隔离、成员与角色管理
    ├── Token 监控 —— 用量与费用统计图表（实时记账）
    ├── API Key —— 外部调用密钥（普通 Key + 永久 Key）
    └── 环境变量 —— 敏感配置安全存储
```

## 新手四步上手

```
① 添加服务商（填 API Key）→ ② 添加模型 → ③ 创建智能体（必须选模型）→ ④ 新建会话开聊
```

## 三种使用方式

| 方式 | 适合谁 | 怎么用 |
|---|---|---|
| 网页对话 | 平台内用户 | 登录后进「会话」直接聊 |
| IM 机器人 | 全体同事 | 私聊直接发；飞书 / 钉钉 / 企微群聊需 @机器人 |
| API 接入 | 开发者 / 外部系统 | 申请 API Key 后调用开放接口 |

## 亮点功能

- **多模型自由切换**：一个平台接入多家 AI 服务商，按需选用
- **工具调用安全可控**：5 档权限模式；危险输入（如删除命令、敏感文件）任何模式下都强制确认
- **微信扫码接入**：微信机器人扫码即可上线，无需复杂配置
- **群聊共享上下文**：飞书 / 钉钉 / 企微群里整个团队和 AI 共享一份对话记忆
- **费用看得见**：Token 用量和费用实时记账，按模型 / 智能体 / 会话多维可视化
- **定时自动化**：设好周期，AI 定时完成报告、巡检等重复工作，日志完备
- **多租户隔离**：不同团队数据互不可见，「公开」开关按需共享
