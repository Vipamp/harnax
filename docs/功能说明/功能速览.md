# Harnax 功能速览（一页版）

> 适合快速了解平台能做什么。详细说明见 [平台功能说明](./平台功能说明.md)。

## 功能地图

```
Harnax 平台
├── 登录与首页
│   ├── 账号密码 / 短信验证码 / GitHub 登录
│   └── 首页概览（模型数、工具数、今日请求、活跃用户）
│
├── 智能体
│   ├── 智能体管理 —— 创建、配置、启停 AI 智能体
│   ├── 会话对话 —— 网页上和 AI 聊天（流式回复、传图、工具确认）
│   └── 定时任务 —— 让 AI 按计划自动执行工作
│
├── 上下文管理
│   ├── 模型管理 —— 接入 OpenAI、通义千问、Ollama 等模型
│   ├── 工具管理 —— 浏览平台内置工具
│   ├── MCP 服务 —— 接入外部能力服务，自动发现工具
│   ├── 技能管理 —— 从 GitHub 等仓库同步技能包
│   ├── CLI 工具 —— 给 AI 运行环境预装命令行工具
│   └── 通道管理 —— 接入飞书 / 微信 / 钉钉 / 企业微信机器人
│
└── 系统管理（管理员）
    ├── 用户管理 —— 账号增删改查、启停
    ├── 租户管理 —— 多团队数据隔离、成员管理
    ├── Token 监控 —— 用量与费用统计图表
    ├── API Key —— 外部调用密钥、永久 Key
    └── 环境变量 —— 敏感配置安全存储
```

## 三种使用方式

| 方式 | 适合谁 | 怎么用 |
|---|---|---|
| 网页对话 | 平台内用户 | 登录后进「会话对话」直接聊 |
| IM 机器人 | 全体同事 | 在飞书 / 微信 / 钉钉 / 企业微信里 @机器人 |
| API 接入 | 开发者 / 外部系统 | 申请 API Key 后调用开放接口 |

## 亮点功能

- **多模型自由切换**：一个平台接入多家 AI 服务商，按需选用
- **工具调用有确认**：AI 执行操作前先征求你的同意，危险操作二次确认
- **微信扫码接入**：微信机器人扫码即可上线，无需复杂配置
- **费用看得见**：Token 用量和费用按模型 / 智能体 / 会话多维度可视化
- **定时自动化**：设好周期，AI 定时完成报告、巡检等重复工作
- **多租户隔离**：不同团队数据互不可见，用户可跨租户切换
