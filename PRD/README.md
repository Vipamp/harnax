## 📊 项目核心数据

### 功能统计
- **核心模块**: 11 个
- **P0 功能**: 8 个模块（60%）
- **P1 功能**: 15 个增强功能（30%）
- **P2 功能**: 8 个优化功能（10%）
- **数据表**: 16 个
- **API 端点**: 80+ 个

### 技术栈
- **后端**: Spring Boot 3.5.8 + Kotlin 2.2.20
- **前端**: React 18 + Ant Design 5 + Umi 4
- **数据库**: MySQL 8.0 + MyBatis
- **Agent 框架**: AgentScope 1.0.10
- **测试**: JUnit 5 + Testcontainers

### 当前状态
- **已上线版本**: V1.1
- **开发中版本**: V1.2
- **规划中版本**: V2.0、V2.1

## 💡 使用建议

### 对于产品团队
1. 先从 `feature_list.md` 了解功能全貌
2. 深入阅读 `PRD.md` 的"详细功能说明"章节
3. 参考"迭代规划"制定产品路线图

### 对于开发团队
1. 阅读 `architecture.md` 了解技术架构
2. 查看 `feature_list.md` 的 API 端点清单
3. 参考 `PRD.md` 的"非功能需求"了解性能和安全要求

### 对于测试团队
1. 阅读 `PRD.md` 的"详细功能说明"了解业务逻辑
2. 查看"异常处理"和"质量检查"章节
3. 参考 `feature_list.md` 的完整性检查

### 对于新成员
1. 按顺序阅读：`feature_list.md` → `PRD.md` → `architecture.md`
2. 重点关注"术语表"了解专业词汇
3. 查看"核心业务流程"图理解系统运作

## 🌟 项目亮点

1. **完整的功能体系**: 从 Agent 创建到多渠道接入，覆盖 AI 应用全生命周期
2. **企业级安全**: JWT 认证、数据隔离、Token 黑名单、权限控制
3. **灵活扩展**: 插件化架构，支持自定义模型、技能、MCP 服务
4. **成本透明**: 完整的 Token 监控和费用统计
5. **现代技术栈**: Spring Boot 3 + Kotlin + React + TypeScript
6. **高质量代码**: 集成测试覆盖率 80%+，Testcontainers 真实数据库测试
