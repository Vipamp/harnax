## 🎯 统一替换规则

### EditButton 替换

**查找模式**:
```tsx
<Tooltip title="编辑">
  <Button
    type="link"
    size="small"
    icon={<EditOutlined />}
    onClick={() => handleEdit(record)}
    style={{ padding: '4px', color: '#1890ff' }}
  />
</Tooltip>
```

**替换为**:
```tsx
<EditButton onClick={() => handleEdit(record)} />
```

### DeleteButton 替换

**查找模式**:
```tsx
<Popconfirm title="确定删除?" onConfirm={() => handleDelete(record.id)}>
  <Tooltip title="删除">
    <Button
      type="link"
      size="small"
      danger
      icon={<DeleteOutlined />}
      style={{ padding: '4px' }}
    />
  </Tooltip>
</Popconfirm>
```

**替换为**:
```tsx
<DeleteButton 
  onConfirm={() => handleDelete(record.id)}
  confirmTitle="确定删除?"
/>
```

### TestButton 替换

**查找模式**:
```tsx
<Tooltip title="测试">
  <Button
    type="link"
    size="small"
    icon={<ThunderboltOutlined />}
    onClick={() => handleTest(record.id)}
    style={{ padding: '4px', color: 'var(--vip-warning)' }}
  />
</Tooltip>
```

**替换为**:
```tsx
<TestButton onClick={() => handleTest(record.id)} />
```

### SyncButton 替换

## ✨ 优势总结

### 代码简化
- **旧版**: 10-15行代码(Tooltip + Button + 样式)
- **新版**: 1-3行代码(独立组件)
- **减少**: 约 70-80% 代码量

### 样式统一
- 所有编辑按钮样式完全一致
- 所有删除按钮样式完全一致
- 自动阻止事件冒泡
- 内置国际化支持

### 维护简单
- 修改一处,全局生效
- 类型安全(TypeScript)
- 易于测试

### 场景无关
- 不区分卡片或表格
- 任何地方都能使用
- 灵活组合(Space 包裹)

## 📝 注意事项

1. **保留 Space 组件**: 多个按钮组合时使用 `<Space size={8}>` 包裹
2. **国际化 key**: 使用页面的 intl.formatMessage 传递自定义文案
3. **权限控制**: 保持原有的 hasOperationPermission 判断
4. **事件处理**: 独立组件已默认阻止事件冒泡,无需额外处理
5. **删除旧的导入**: 移除 EditOutlined, DeleteOutlined 等图标导入(如果不再使用)
