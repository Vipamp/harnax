# 独立按钮组件使用指南

## 📦 组件概述

本项目提供6个独立的操作按钮组件,可以在任何场景(卡片、表格等)中使用:

1. **EditButton** - 编辑按钮
2. **DeleteButton** - 删除按钮
3. **TestButton** - 连接测试按钮
4. **SyncButton** - 仓库同步按钮
5. **RunButton** - 立即执行按钮
6. **StartPauseButton** - 启动/暂停切换按钮

---

## 1️⃣ EditButton - 编辑按钮

**位置**: `/src/components/EditButton/index.tsx`

### 基础用法

```tsx
import EditButton from '@/components/EditButton';

// 仅图标(默认)
<EditButton onClick={() => handleEdit(record)} />

// 带文字
<EditButton 
  onClick={handleEdit} 
  showText 
/>

// 自定义颜色
<EditButton 
  onClick={handleEdit} 
  color="#52c41a" 
/>

// 自定义提示
<EditButton 
  onClick={handleEdit} 
  tooltip="修改信息" 
/>
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| onClick | () => void | ✅ 必填 | 点击回调 |
| tooltip | string | 'Edit' | 自定义提示文本 |
| color | string | 'var(--vip-primary)' | 自定义颜色 |
| size | 'small' \| 'middle' \| 'large' | 'small' | 按钮尺寸 |
| showText | boolean | false | 是否显示文字 |
| text | string | '编辑' | 自定义按钮文字 |
| stopPropagation | boolean | true | 阻止事件冒泡 |

## 📊 组合使用示例

### 在卡片中使用

```tsx
import { Space } from 'antd';
import EditButton from '@/components/EditButton';
import DeleteButton from '@/components/DeleteButton';
import TestButton from '@/components/TestButton';

// Agent/MCP 卡片操作
<Space size={8}>
  <TestButton onClick={() => handleTest(item.id)} />
  <EditButton onClick={() => handleEdit(item)} />
  <DeleteButton onConfirm={() => handleDelete(item.id)} />
</Space>
```

### 在表格中使用

```tsx
import { Space } from 'antd';
import EditButton from '@/components/EditButton';
import DeleteButton from '@/components/DeleteButton';

// 表格操作列
{
  title: '操作',
  key: 'action',
  render: (_, record) => (
    <Space size={8}>
      <EditButton onClick={() => handleEdit(record)} />
      <DeleteButton 
        onConfirm={() => handleDelete(record.id)}
        confirmTitle="确定要删除吗?"
      />
    </Space>
  ),
}
```

### 在仓库列表中使用

```tsx
import { Space } from 'antd';
import EditButton from '@/components/EditButton';
import DeleteButton from '@/components/DeleteButton';
import SyncButton from '@/components/SyncButton';

// Repository 卡片操作
<Space size={8}>
  <SyncButton onClick={() => handleSync(repository)} />
  <EditButton onClick={() => handleEdit(repository)} />
  <DeleteButton onConfirm={() => handleDelete(repository.id)} />
</Space>
```

## 🌍 国际化支持

所有按钮文案都支持国际化,默认使用以下 key:

## 6️⃣ StartPauseButton - 启动/暂停切换按钮

**位置**: `/src/components/StartPauseButton/index.tsx`

### 基础用法

```tsx
import StartPauseButton from '@/components/StartPauseButton';

// 根据状态自动显示启动或暂停图标
<StartPauseButton 
  status={record.jobStatus} // 0: 停止, 1: 运行中
  onToggle={(newStatus) => {
    if (newStatus === 1) {
      handleStart(record.id);
    } else {
      handlePause(record.id);
    }
  }}
/>

// 带文字
<StartPauseButton 
  status={record.jobStatus}
  onToggle={handleToggle}
  showText
/>

// 自定义颜色
<StartPauseButton 
  status={record.jobStatus}
  onToggle={handleToggle}
  startColor="#52c41a"  // 启动按钮颜色
  pauseColor="#faad14"  // 暂停按钮颜色
/>
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| status | number | ✅ 必填 | 当前状态 (0: 停止, 1: 运行中) |
| onToggle | (newStatus: number) => void | ✅ 必填 | 状态切换回调 |
| tooltip | string | 自动根据状态生成 | 自定义提示文本 |
| startColor | string | `var(--vip-success)` | 启动按钮颜色 |
| pauseColor | string | `var(--vip-warning)` | 暂停按钮颜色 |
| size | 'small' \| 'middle' \| 'large' | 'small' | 按钮大小 |
| showText | boolean | false | 是否显示文字 |
| stopPropagation | boolean | true | 是否阻止事件冒泡 |

---

## 📝 注意事项

1. **事件冒泡**: 默认阻止事件冒泡(`stopPropagation=true`),在卡片中使用时可防止触发卡片点击事件
2. **删除确认**: DeleteButton 内置 Popconfirm,点击后会先弹出确认弹窗
3. **加载状态**: SyncButton 支持 loading 属性,加载时图标会旋转
4. **颜色自定义**: 可以通过 `color` 属性覆盖默认颜色
